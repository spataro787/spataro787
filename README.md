Servidor MCP (Model Context Protocol) que expone 5 herramientas (*tools*) para permitir a agentes de Inteligencia Artificial interactuar en tiempo real con GitHub (crear/listar repositorios e issues, y crear commits). Implementa transporte Streamable HTTP, validación de datos con Zod y 17 tests automatizados en Vitest.

**Technologies:** Node.js, TypeScript, Express, MCP SDK, Streamable HTTP, Zod, Octokit, Vitest.
